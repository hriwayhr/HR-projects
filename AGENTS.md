# iTeamboard — портал и HR-метрики

Рабочий сайт: https://iteamboard.ru/. Репозиторий: `hriwayhr/HR-projects`.
Ветка портала: `claude/lucid-galileo-jpib8n`. Для задач по порталу используй
её как базовую ветку и выбирай её же целью PR. Ветка репозитория по
умолчанию содержит другой прототип.

## Разработка и проверка

- Портал: `src/iway-portal.html`. HR-метрики: `src/hr-metrics.html`.
- Сервер: `server/server.js`; обработчики, права, вход и хранилище:
  `cloud/function/{index,acl,auth,store}.js`.
- Сохраняй серверные проверки входа и прав. Не добавляй в репозиторий
  секреты, `.env`, копии базы и реальные данные сотрудников. Для тестов
  используй вымышленные записи; не встраивай рабочие данные в HTML.
- Проверяй изменения с Node.js 22 или новее:

  ```sh
  node --test server/test.js cloud/function/test/*.test.js
  ```

## Публикация

Сервер проверяет ветку `claude/lucid-galileo-jpib8n` примерно раз в минуту.
После появления нового коммита в ней сервер собирает и проверяет всю версию
ветки на копии SQLite, затем выкладывает её. Создание PR само по себе
не запускает выпуск: он начнётся после слияния PR в указанную ветку.
При неудачном выпуске рабочая версия сохраняется или восстанавливается.

В образ входят семь файлов приложения, перечисленные выше. Новые файлы,
зависимости и изменения инфраструктуры нужно согласовать с администратором:
он обновляет доверенную сборку. `server/setup.sh` предназначен для установки
на отдельный сервер и в этой схеме не используется.

Из облачного Codex работай с GitHub. Для правок и обычной публикации
подключение к серверу по SSH не требуется.
