HR-МЕТРИКИ — ЛОКАЛЬНАЯ ВЕРСИЯ (Windows + сетевая папка)

Как это устроено
- Папка «HR-метрики» лежит в общей сетевой папке («Обменник»).
- Каждый запускает программу у себя двойным щелчком по «Запустить HR-метрики».
  Открывается браузер с HR-метриками. Работает в любом браузере: Chrome, Edge, Яндекс, Firefox.
- Все действия сохраняются сразу и автоматически в папку data рядом с программой.
- Правки коллеги появляются у вас через 1–2 секунды, без перезагрузки страницы.
  Вы работаете в одних данных.
- Интернет не нужен. В сеть программа ничего не открывает: каждая копия работает только для своего ПК.

Первый запуск (делает один человек, один раз)
1. Распакуйте архив в «Обменник»: должна получиться папка «HR-метрики».
2. Откройте «Запустить HR-метрики».
3. На экране «Первый запуск» нажмите «Выбрать файл» и выберите ваш файл «HR-метрики.html»
   (версия для ПК, в которой вы работали). Команда, логины, пароли и все данные перенесутся.
4. Войдите своим логином и паролем.
Коллега просто открывает «Запустить HR-метрики» из той же папки и входит своим логином.

Каждый день
- Откройте «Запустить HR-метрики». Если программа уже запущена, просто откроется браузер.
- Свёрнутое окно «HR-metrics - do not close this window» — это сама программа.
  Не закрывайте его, пока работаете. Закрыли случайно — снова «Запустить HR-метрики».

Обновление программы
- Замените в «Обменнике» только папку program на новую из архива.
- Папку data НЕ трогайте: в ней все данные.
- Перед заменой закройте программу у себя и попросите коллегу сделать то же.

Сохранность данных
- Все данные — в папке data. Раз в неделю копируйте её в надёжное место.
- Дополнительно программа сама каждый день делает копию в data\backups (хранятся 60 дней).
- Ничего не удаляйте и не правьте руками в папке data.

Если что-то не так
- «The program did not start» — разверните окно «HR-metrics» и посмотрите причину.
  Если Windows не даёт запускать программы из сетевой папки, обратитесь к IT.
- Windows спрашивает «Разрешить доступ?» — можно нажать «Отмена»: программе сеть не нужна.
- Архив скачан из интернета, и Windows ругается на файлы — до распаковки:
  правой кнопкой по архиву → Свойства → поставьте галочку «Разблокировать» → OK.
