# HR-метрики i’way — история работы

Сессия с Claude Code, октябрь 2026. Ветка репозитория: `claude/lucid-galileo-jpib8n`
(`hriwayhr/HR-projects`). Рабочая версия на claude.ai: <https://claude.ai/artifact/LT73wVkVx9bYcwANYwPVt1>.

## Итог

- **Рабочее пространство HR** — одна страница `src/hr-metrics.html`: дашборд, ввод дня, сводка, вакансии,
  настройки, аналитика. Работает на claude.ai (версия 31) и в облачном режиме на своём сервере.
- **Серверная часть** — `cloud/function`: вход через Яндекс 360, права на сервере, хранилище
  (YDB / SQLite / память), журнал изменений, ночные копии.
- **Варианты размещения**: Yandex Cloud (`cloud/`, `cloud/README.md`) и свой сервер Selectel
  (`server/`, `server/README.md`).
- **Импорт истории** из `Workload.xlsx` — `tools/import_workload.py`.
- **Тесты**: `tests/flow24–27.py` (браузер), `tests/test_import.py`, `cloud/function/test/`, `server/test.js`.

## Хронология запросов

### 1. Основа (из Workload.xlsx)
- Google Sheet по ссылке был недоступен — взяли выгрузку `Workload.xlsx`.
- Сделаны дашборд дня, ввод дня и сводка; данные с июля 2024 перенесены импортёром (формулы в шапке,
  проверка дней недели, отметки отпуска «о»).

### 2. Кабинеты и роли
- Кабинет администратора (пользователи, метрики, ввод за любого) и кабинеты рекрутеров с входом.
- Юля и Юлия объединены в одного администратора; архив пользователей с сохранением истории —
  в отчётах пометка «(архив)».
- Фамилии в команде; «Анна» и «Шулятицкая» в вакансиях — один человек (сопоставление по фамилии).
- Тестовый вход test/test — администратор без вклада в метрики.

### 3. Вакансии
- Реестр из листа «вакансии в работе», скорость закрытия; фильтр по умолчанию «активные».
- Отчёт «Текущий найм» по менеджерам — копирование для письма.
- Несколько публикаций hh.ru в карточке: дата открытия и архивации, «Продление» (+1 месяц, можно
  подряд), просроченные не считаются и подсвечиваются, напоминание за 5 дней, «Не продлеваем».
  Подпись публикации — только дата архивации.
- Поля «Заказчик», стоимость публикаций (вручную), несколько ставок (единицы с датой запроса и выхода).
- Синхронизация с метриками дня с 05.10.2026: «вакансии» = публикации hh.ru, «кандидаты» = сколько
  людей нужно. Историю до этой даты по просьбе не трогали.

### 4. Сводка и отчёты
- Формат листа sum: блоки по месяцам, недели ISO, CV %; разбивка по неделям, месяцам, кварталам.
- Кнопка копирования недельного отчёта для дирекции; отказы из сводки убраны.
- Метрики Немчиновой за сентябрь перепроверены по скриншоту.

### 5. Учёт и отпуска
- Подсветка невнесённых дней; учёт с июля 2024, пропуски считаются с 28.09.2026, раньше — отпуск.
- Статус «в отпуске»; вкладка «Настройки» у администратора: Команда, Метрики, Отпуска.
- «По ответственным» — только действующие пользователи.

### 6. Дашборд
- Инфографика рабочей недели. Блок «мотивации» сделан и по просьбе убран.
- Период: день, неделя, месяц, квартал (выбор из списка), год, свой период; сравнение с тем же сроком
  прошлого периода.
- Плитки раскрывают подробности: график по частям периода и разбивка по людям.
- Пиковые дни недели: чаты, собеседования, доходимость, выходы — суммы по пн–пт, пик выделен.
- Аналитика: воронка и «сколько нужно на один выход», тренд за 12 месяцев против прошлого года,
  сроки закрытия по этапам (по отделам, заказчикам, ответственным), нагрузка рекрутеров
  и ожидаемые выходы с план/фактом месяца.
- Испытательный срок (2 месяца, отслеживается с 01.08.2026): кто на ИС, кнопки «Прошёл» / «Не прошёл»,
  доля прошедших; увольнения — из метрик дня.
- Причины отказов из выгрузки Talantix (Excel или CSV; Excel читается без сторонних библиотек).

### 7. Размещение вне claude.ai
- **Обсуждение вариантов**: Firebase, Supabase, Google Apps Script — данные за рубежом (152-ФЗ).
  Выбран Yandex Cloud.
- **Безопасность**:
  - вход через Яндекс 360 вместо своих паролей;
  - права проверяет сервер;
  - почта при первом входе привязывается к аккаунту Яндекса — против входа личным Яндекс ID
    с подтверждённым рабочим адресом;
  - CSP с одноразовым nonce, журнал изменений, ночные копии.
- **Изоляция от продуктов компании.** Для Yandex Cloud рекомендована отдельная организация с отдельным
  владельцем и счётом: стоит около 0–100 ₽ в месяц в пределах бесплатного объёма; цифры сверить
  на сайте. Альтернатива — отдельный сервер в Selectel.
- **Комплект для Selectel**: Docker + Caddy (HTTPS), SQLite, скрипт настройки сервера
  (файрвол, обновления, SSH по ключу).

## Предупреждения, которые остаются в силе

- **Версия на claude.ai** открыта по ссылке; там вход по паролям, их хеши видны в базе страницы;
  test/test — администратор с простым паролем. После переезда отправить test в архив.
- **Праздники** в расчётах не учитываются; вакансии без ссылки не считаются «открытыми вакансиями».
- **Воронка** — суммы за период, а не путь одних и тех же кандидатов.
- **Испытательный срок** — один для всех (2 месяца), продлить отдельному человеку нельзя.
- **Многоставочная вакансия** закрывается при пересохранении, если у всех единиц есть дата выхода,
  даже будущая.
- **Формат выгрузки Talantix** не проверен на реальном файле — нужен пример.
- **YDB-хранилище** не запускалось на настоящей YDB (только локальные тесты на памяти и SQLite);
  скрипт `cloud/deploy.sh` написан по документации и на реальном аккаунте не выполнялся.
- **152-ФЗ**: уведомление РКН, политика обработки, согласия кандидатов — на стороне компании.
